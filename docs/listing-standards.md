# FarmCash Listing Standards – Creation & Updates

> These rules define how all listings must be created and updated.
> Any deviation must be explicitly approved.

---

## Purpose

Defines the required structure, content, and formatting for all FarmCash listings.

Ensures consistency, quality, and conversion performance across the platform.

---

## 🚨 DO NOT BREAK

- Price must always include `+ VAT` (if priced)
- Title must follow Year + Make + Model format
- Buyers Love section must be included
- Listings must be clear, accurate, and commercially honest
- No placeholder or incomplete listings should be published

If any of the above are not met, do not publish.

---

## Listing Structure (REQUIRED)

All listings must follow this structure:

1. Listing ID  
2. Title  
3. Price  
4. Key Details  
5. Buyers Love  
6. Description  
7. Images  

---

## 1. Listing ID (REQUIRED)

Format:
FC-YYYY-XXX

Example:
FC-2014-001

Rules:
- Must be unique  
- Must be included in every listing  

---

## 2. Title Format (REQUIRED)

Format:
Year + Make + Model

Example:
2014 New Holland T6.140

Rules:
- No extra wording  
- No sales language  
- No capitalisation inconsistencies  

---

## 3. Price (CRITICAL)

- Must always include `+ VAT` if a price is shown  
- Use one of the following formats:

### Fixed Price
£24,750 + VAT  

### POA
Price on Application  

### Rules

- Do not leave price blank  
- Do not mix formats  
- Do not write “inc VAT”  

---

## 4. Key Details (REQUIRED)

Include core machine information:

- Hours  
- Condition  
- Location (if relevant)  
- Key specifications (short form only)

### Rules

- Keep concise  
- Avoid long paragraphs  
- Focus on decision-making info  

---

## 5. Buyers Love (REQUIRED)

2–4 bullet points highlighting key selling points.

### Format

- Benefit-led  
- Short and punchy  
- Buyer-focused language  

### Example

- Ready to go straight to work  
- Clean, well-maintained example  
- Reliable and popular model  

---

## 6. Description (REQUIRED)

Short supporting paragraph expanding on the listing.

### Rules

- Clear and honest  
- No exaggeration  
- No unnecessary filler  
- Written in plain English  

---

## 7. Images (REQUIRED)

- Use clear, high-quality images  
- Show multiple angles where possible  
- Avoid duplicates  
- Avoid low-resolution images  

---

## Listing Quality Rules

- No placeholders (e.g. “more info to follow”)  
- No missing sections  
- No inconsistent formatting  
- No overuse of capital letters  
- No misleading claims  

---

## Update Rules

When updating a listing:

- Maintain original structure  
- Do not remove Buyers Love section  
- Ensure pricing format remains correct  
- Keep formatting consistent  

---

## Regression Checklist (MANDATORY)

Before publishing or updating:

- [ ] Title follows correct format  
- [ ] Price includes `+ VAT` or is clearly POA  
- [ ] Buyers Love section included  
- [ ] Key details present and clear  
- [ ] Description complete  
- [ ] Images included and clear  
- [ ] No placeholders or missing content  

---

## Ownership
